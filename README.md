# 💸 Expenditures — Smart Expense Tracking System

> A modern, full-stack expense tracking application built to simplify financial management and deliver actionable insights. Built Using Claude Code

---

## 🚀 Overview

**Expenditures** is a full-stack web application designed to help users track, analyse, and optimise their spending habits.

It goes beyond basic expense logging by providing:

* Structured financial tracking
* Category-based insights
* Interactive dashboards
* Scalable backend architecture

This project is part of my ongoing journey in **data-driven product development** and **system design**.

---

## ✨ Features

### ✅ Implemented

* 🔐 Authentication (Google & GitHub OAuth)
* 📊 Interactive dashboard with financial insights
* 💳 Categorised expense tracking
* 📅 Monthly transaction trends
* 🔍 Transaction filtering & history
* 🗂️ Category management (CRUD)
* ⚡ Real-time updates
* 🎨 Responsive UI (Shadcn + Tailwind)

### ⏳ Upcoming

* 🔔 Recurring expense reminders
* 📈 Advanced analytics & reports
* 🎯 Goal-based financial planning
* 💡 Smart budgeting tips & alerts

---

## 🧠 Why This Project?

Most expense trackers stop at recording transactions.
**Expenditures focuses on insight generation.**

The goal is to evolve this into:

* A **data-driven financial assistant**
* A system capable of **behavioral analysis**
* A foundation for **ML-based spending predictions**

## ⚙️ Installation

```bash
# Clone the repo
git clone https://github.com/srvmann/Expenditures.git

# Navigate into the project
cd Expenditures

# Install dependencies
npm install

# Run development server
npm run dev
```
